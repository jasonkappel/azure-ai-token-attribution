AI Spend Attribution

Per-principal token usage and list-price cost across two patterns, in one portal. Queried live from Azure Log Analytics.

Not configured

This portal is live-only and ships with no sample data.

Fill config.sample.json (save as config.json), run query-helper.ps1 to generate data.json, then reload.

How to read these numbers. Token counts are real/measured. Department / app / user are app-supplied enrichment on each call's Entra oid (when the enrichment table is wired; otherwise principals show by oid). Dollars are a list-price estimate — reconcile to Azure Marketplace / Cost Management before chargeback. Cache-write is billed at a premium, cache-read at a discount; thinking / reasoning tokens are already inside output and are shown for transparency only, never added to cost. A blank meter (—) means the meter exists but was not captured on this query path; n/a means no such meter for that pattern.
